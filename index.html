Summary

Between 14:02 and 14:21 UTC, payments-api experienced elevated error rates (up to 34%) due to database connection pool exhaustion, resulting in failed checkout requests for approximately 6,200 users.

Root Cause

Deploy #a91fe2c introduced a code path that failed to release database sessions on a specific error branch, causing the connection pool to saturate under normal traffic within ~9 minutes of rollout.
